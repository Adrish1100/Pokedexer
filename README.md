# Pokédexer

A responsive Pokémon browser built with HTML, CSS, and vanilla JavaScript. Search, filter by type/generation, and browse stats. Uses [PokéAPI](https://pokeapi.co/).

## Features
- **Search by Name**: Find Pokémon instantly
- **Filter by Type**: Primary + secondary type filters
- **Filter by Generation**: Gen I–IX support
- **Pagination**: Next/Prev with dynamic card count based on screen width
- **Responsive Grid**: Auto-adjusts cards for desktop/mobile
- **Dark UI**: Custom CSS variables, always-on dark theme
- **Hamburger Menu**: Mobile-friendly filters sidebar

## Tech Stack
- HTML5 + CSS3 (Grid, Flexbox, CSS Variables)
- Vanilla JavaScript ES6+ with fetch API
- PokéAPI for data
